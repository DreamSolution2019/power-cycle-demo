전원을 꺼도 각도를 기억할까?

전원을 끈 채로 샤프트를 돌리고 다시 켜보세요. EN25-Absolute는 켜자마자 현재 각도를 알려줘요
상품 상세정보 보기 ↗
🎬 체험 모드 — 엔코더 없이 가상의 엔코더가 전원을 껐다 켜며 자동으로 시연해요. 실제 EN25-Absolute를 연결하면 이 화면이 그대로 동작해요.
EN25-Absolute 구매하기 ↗
이 브라우저는 USB 시리얼 연결(Web Serial)을 지원하지 않아요. 실제 엔코더 연결은 PC의 Chrome 또는 Edge 에서 할 수 있어요. 위의 ‘체험 시작’으로 동작을 미리 볼 수 있어요.
연결 대기 ‘엔코더 연결’ 버튼을 눌러 COM 포트를 선택하세요.

연결

연결 안 됨
  1. 샤프트를 아무 각도로 돌려 두세요.
  2. 전원을 끄세요 — 빨간선(5V)을 분리하거나 USB를 뽑으면 돼요.
    (USB를 다시 꽂으면 자동으로 다시 연결돼요)
  3. 꺼진 상태에서 샤프트를 다른 각도로 돌리세요.
  4. 전원을 다시 켜고 두 값을 비교해 보세요.

설정

눌러서 가상 엔코더 전원을 끄고 켜요

전원 재투입 기록

재투입 0회 회전 후 재투입 0회 제자리 재투입 0회 · 최대 차이 –
회차꺼진 시각꺼져 있던 시간OFF 직전 각도 ON 직후 각도꺼진 동안 회전판정인크리멘탈(가상)
아직 기록이 없어요. 전원을 껐다 켜면 여기에 쌓여요.
  • 제자리 재투입: 돌리지 않고 껐다 켠 경우예요. 이때의 차이가 작을수록 전원을 켜도 같은 각도를 정확히 기억한다는 뜻이에요.
  • 누적 회전수(rev)는 전원을 켜면 0부터 다시 세요. 전원이 꺼져도 유지되는 값은 한 바퀴 안의 절대 각도(0~359.9°)예요.

📦 이 예제 소스코드 무료 다운로드

EN25-Absolute만 있으면 지금 보시는 화면을 그대로 실행할 수 있어요. 웹페이지는 설치 없이 Chrome·Edge로 열기만 하면 되고, 파이썬 코드는 IDLE에서 F5로 실행됩니다.

EN25-Absolute 구매하기 ↗
  • 준비물: 앱솔루트 로터리엔코더 EN25-Absolute, USB TO RS232/TTL 컨버터 모듈, PC (모든 준비물은 구매하기에서 구매가능)
  • 배선: 빨강 → 5V, 초록 → GND, 흰색(RS232) → USB TO RS232/TTL 컨버터 모듈의 RX · 통신속도 38400bps
  • 파이썬: Python 3 설치 후 pip install pyserial → 파일 위쪽의 PORT 값만 맞추고 실행
